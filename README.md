# Azagro

ERP operativo de AZ Insumos Agrícolas. Circuito de venta/compra, kardex y cartera (TIIE / FEGA / días 360) para dejar atrás Compaq+Excel en la operación diaria. Compaq sigue timbrando.

**Si eres Claude:** lee `CLAUDE.md` y `HANDOFF.md` antes de editar.

```bash
npm install
npm run dev
npm test
```

Con `DATABASE_URL` usa Postgres (Neon). Sin ella, PGLite local.

Repo privado: [mickyarambula/azagro](https://github.com/mickyarambula/azagro)
